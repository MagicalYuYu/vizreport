这是什么

本页由 AOS「调研成果可视化标准」生成：布局与渲染器固定（零依赖单文件 HTML），内容全部来自文件内 <script id="aos-data"> 数据岛——双击即开、离线可用、可直接归档、十年后照样渲染。

复用三步（人或 Agent 均可）

  1. 复制模板 .dsh/skills/research-showcase/assets/showcase.template.html 到 07_EXPORTS/{项目或quicktask}/，按主题改名；
  2. 只改 aos-data JSON 块（字段表见 skill 与 09_REFERENCE 正本），其余一律不动；
  3. 跑验收闸门：impeccable detect 零发现 + Playwright 冒烟（skill 自带脚本）+ 渲染截图目检一轮。

后续 DSH + AOS 会话如何「自觉地」用它（机制闭环）

① 你在新对话里说「把这次调研做成看板 / 可视化 / showcase」→
② Agent 查 AGENTS.md 指针表（已加一行路由：清单型调研可视化 → skill: research-showcase）→
③ DSH 自动发现并加载 .dsh/skills/research-showcase/SKILL.md（触发词已写入其 description）→
④ Agent 按 skill 指引：复制模板 → 改数据岛 → 跑三项闸门 → 交付到 07_EXPORTS/ 并在 06_LOGS 记一行。

你不需要记任何路径——触发词 + AGENTS.md 指针表就是记忆锚点。规范正本（五方案对比矩阵 / 数据 Schema / 设计令牌 / 坑点清单）只存一份：09_REFERENCE/research/2026-11-12_visual-showcase-standard.md。

本页的人性化设施

  • 字号：层级压缩——最小文字 ≥15px、大标题/封面图形同步收敛，100% 即可读，不再"小字太小/放大后大字太大"；右侧常驻工具条 A− / A+ 五档随时可调，选择会被本页记住；
